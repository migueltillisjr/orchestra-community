# Event Posting Research

Create an exhaustive, well-sourced list of websites, event calendars, community boards, media calendars, newsletters, Facebook groups, Reddit communities, city calendars, chamber of commerce calendars, local business directories, arts/culture calendars, family calendars, nonprofit calendars, and paid event-discovery platforms where I can post or promote an event happening in the San Francisco Bay Area.

## Geographic Coverage

The event is happening in the Bay Area, so include resources for:

- San Francisco
- Oakland
- Berkeley
- Alameda
- Emeryville
- San Jose
- San Mateo
- Marin
- East Bay
- South Bay
- Peninsula
- Greater Bay Area

## Required Fields For Each Entry

For each site or event page, include:

- Name of the site/platform
- Direct link to the event submission page, calendar page, or posting instructions
- Type of platform, such as event marketplace, community calendar, city calendar, newsletter, local media, arts/culture, family-friendly, business/networking, nightlife, nonprofit, tech/startup, faith/community, college/university, or social group
- Whether posting appears to be free, paid, or unclear
- Best fit/event type
- Audience/location served
- Submission requirements, such as images, descriptions, ticket links, approval process, deadlines, or account required
- Estimated usefulness score from 1–5
- Reason for the score
- Source link used to verify the information

## Selection Criteria

- Prioritize sources that have a clear event-submission page or public calendar
- Prioritize Bay Area-specific platforms over national platforms
- Prioritize sites with active audiences, local relevance, and real discovery value
- Include national platforms only if they are commonly used for Bay Area event discovery, such as Eventbrite, Meetup, Facebook Events, LinkedIn Events, Dice, Luma, Partiful, AllEvents, Bandsintown, Resident Advisor, or similar
- Include niche platforms if they match specific event categories, such as tech, business, networking, music, art, family, wellness, nonprofit, education, nightlife, food, culture, or community
- Exclude dead pages, inactive calendars, spammy directories, or sites that do not allow public event submissions
- When unsure whether a platform is still active, verify using the most recent available page or event listings

## Output Sections

Organize the output into these sections:

- Best overall platforms
- Bay Area-wide event calendars
- San Francisco event calendars
- Oakland and East Bay event calendars
- Berkeley and university/community calendars
- South Bay and San Jose event calendars
- Peninsula and San Mateo event calendars
- Arts, music, nightlife, and culture calendars
- Business, startup, tech, and networking calendars
- Family-friendly and community calendars
- Nonprofit, civic, and neighborhood calendars
- Social media, Reddit, Facebook, and LinkedIn places to post
- Paid promotion options
- Final recommended posting strategy

Return the results in a markdown table with columns as a single markdown file:
