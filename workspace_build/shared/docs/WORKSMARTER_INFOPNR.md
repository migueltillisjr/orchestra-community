# Info Pioneer Marketing Prompt Playbook: Event Promotion and Funnel Optimization

This is a practical SOP and tutorial for using the Ai prompts in this folder with any AI tool.

Use this doc when you want to:
- Research where to promote an event
- Generate business event posts quickly
- Evaluate and improve your online business funnel quality
- Maintain consistency accross campaigns

## Scope

Prompt files covered:
- EVENT_POST_PROMPT.md
- EVENT_POSTING_RESEARCH_PROMPT.md
- FUNNEL_RUBRIC_PROMPT.md

## Quick Start (5 Minutes)

1. Open your AI tool, Anthropic Claude, ChatGPT, Gemini etc.
2. Copy the full text from the prompt of your choice and paste it into the AI.
3. Ask the Ai to modify the prompt to your liking
4. Once happy with modifications, Ask Ai to run your prompt

## SOP: End-to-End Prompt Usage

### Research Distribution Channels

Objective:
- Build a high-quality posting list before writing copy.

Action:
- Open EVENT_POSTING_RESEARCH_PROMPT.md.
- Copy the full file contents.
- Paste into your AI tool.
- Run and save output as research reference.

Expected output:
- Platform list with direct submission links
- Free/paid visibility
- Submission requirements
- Usefulness score and rationale
- Recommended posting strategy

Definition of done:
- You have at least 15-30 viable platforms, grouped by geography/category, with links you can use immediately.

### Generate Event Listing Text

Objective:
- Produce ready-to-post copy in short and long forms.

Action:
- Open EVENT_POST_PROMPT.md.
- Copy the full file contents.
- Replace placeholders with real event details.
- Paste into your AI tool and run.

Expected output:
- Catchy headline
- Distinct first-line hook
- Modern, non-generic event description
- Under-500-character version
- 150-250-word version

Definition of done:
- You have at least 2 clean versions you can post across multiple event channels.

### Evaluate Funnel Quality

Objective:
- Identify conversion weaknesses before spending on promotion.

Action:
- Open FUNNEL_RUBRIC_PROMPT.md.
- Copy the full file contents.
- Include your landing page copy or relevant page sections.
- Ask the AI to score and list the top 5 highest-impact fixes first.

Expected output:
- Rubric score by section
- Weaknesses by severity
- Specific recommendations for hook, offer, CTA, trust, and follow-up

Definition of done:
- You have a prioritized fix list and a baseline rubric score.

### Implement and Re-Score

Objective:
- Improve the funnel with evidence-based revisions.

Action:
- Apply top fixes from Step 3.
- Run FUNNEL_RUBRIC_PROMPT again.
- Compare score delta and note changes in conversion readiness.

Definition of done:
- Score increases and key weak sections move from "Not Evident" or "Approaching" toward "Competent."

## Tutorial: How to Run This in Any AI Tool

### Recommended Prompting Pattern

Use this format when submitting prompts:

- Context: what event or funnel you are working on
- Goal: what output you need right now
- Constraints: tone, character limits, geography, audience
- Output format: table, bullets, short/long copy
- Quality check: ask for practical, non-generic output and revision suggestions

### Example Operator Command (add before each prompt)

Paste this before the prompt text:

"Use the prompt exactly as written. Keep output actionable, specific, and formatted in markdown. If information is missing, ask up to 5 concise clarifying questions first; otherwise proceed."

### Quality Control Checklist

Before publishing, verify:
- Links are valid and current
- Copied text is not generic

## Why This System Speeds Production by 60%+

Using these prompts as a fixed operating system has improved creation and evaluation speed by over 60%.

Main reasons:
- Prompt reuse removes blank-page time
- Research, copy, and evaluation are separated into clear stages
- Rubric scoring prevents random edits and keeps revisions targeted
- Re-scoring creates fast feedback loops and better iteration discipline

## Operating Cadence

- Weekly: refresh distribution-channel research.
- Per event: generate and adapt copy for top channels.
- Per page update: run rubric, revise, and re-score.
- Monthly: review lead quality, conversion rates, and rubric trendline.
