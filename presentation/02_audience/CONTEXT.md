# Stage 2 — Define the Audience

## Input

Read `presentation/01_purpose/output/purpose.md`.

## Process

The audience is defined:
- **Who:** All employees — full-time, part-time, managers, remote workers, and any staff who access organizational accounts or sensitive company information.
- **Technical level:** At least basically technical (comfortable with terms like MFA, phishing, access controls).
- **Tone:** Professional, direct, supportive — not condescending, but clear enough that non-engineers follow.
- **Word choice:** Technical terms acceptable (MFA, biometrics, penetration testing, vulnerability assessment) but briefly define protocol-specific jargon on first use.

## Output

Write the following to `presentation/02_audience/output/`:

| File | Contents |
|------|----------|
| `audience.md` | Audience description, tone decisions, and word choice rationale |
