# Stage 6 — Make the Presentation Visually Engaging

## Input

Read `presentation/05_slide_content/output/slides.md`.

## Process

For each slide, suggest **modern, technology-related** visuals:

1. **Title slide** — Shield or lock icon, dark blue/teal gradient background
2. **Threat Landscape** — Warning/alert graphic, network diagram showing attack vectors
3. **The New Protocol** — Three-column layout with icons (key for MFA, magnifying glass for audits, people for training)
4. **Benefits** — Upward trend chart or checklist graphic, green accent colors
5. **What You Need to Do** — Checklist or step-by-step process graphic, clear call-to-action button style

Design direction:
- Colors: Dark blue, white, accent teal/green
- Fonts: Clean sans-serif (e.g., Segoe UI, Calibri)
- Layout: Minimal, modern, ample white space
- Ensure at least **2 visual elements** across the presentation (rubric requirement)

## Output

Write the following to `presentation/06_visuals/output/`:

| File | Contents |
|------|----------|
| `visuals.md` | Visual suggestions for each slide (slide number, suggested visual, layout/color notes) |
