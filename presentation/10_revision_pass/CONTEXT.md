# Stage 10 — Revision Pass

Apply all fixes identified in the evaluation to produce an improved presentation.

## Input

Read `presentation/09_evaluation/output/evaluation.md` for the list of issues and recommendations.
Read `presentation/08_final_assembly/output/final_presentation.html` for the current presentation.

## Process

1. Read the evaluation and identify every criterion rated ⚠️ or ❌.
2. For each non-Competent criterion, apply the recommended fix.
3. Preserve all sections rated ✅ Competent — do not weaken them.
4. Maintain professional tone and visual consistency throughout.

## Output

**Use the `write` tool to save to `presentation/10_revision_pass/output/`.**

| File | Contents |
|------|----------|
| `revised_presentation.md` | The complete revised presentation ready to re-evaluate |

## Run Versioning

- First run: `revised_presentation.md`
- Subsequent runs: `revised_presentation_<YYYYMMDD_HHMMSS>.md`
