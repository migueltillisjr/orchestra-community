# Requirements

## Presentation Specifications

| Property | Value |
|----------|-------|
| **Purpose** | Inform employees and stakeholders about a new cybersecurity protocol (MFA, security audits, employee training) |

## Content Source

The presentation is based on the blog post in `presentation/shared/references/GLOBAL_CONTEXT.md`. Pull main points from there:

1. **Why** — Increasing cyber threats require comprehensive security frameworks (NIST, 2024)
2. **What** — Three components: MFA, regular security audits, employee training
3. **How MFA works** — Something you know + something you have + something you are
4. **Audits** — Quarterly by IT security team (penetration tests, vulnerability assessments, access control reviews)
5. **Training** — Internal security awareness modules
6. **Benefits** — Enhanced security posture, reduced operational disruptions, improved cash flow, culture of security awareness, customer trust

## Slide Requirements

- Minimum of **5 slides**, including a title slide
- Minimum of **2 visual elements** (e.g., diagrams, charts, icons with sources cited)
- Each slide should have one clear main idea
- Use short bullets, clear headings, and strong visual hierarchy
- No speaker notes required
