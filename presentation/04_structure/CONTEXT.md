# Stage 4 — Build a Logical Slide Structure

## Input

Read `presentation/01_purpose/output/purpose.md`, `presentation/02_audience/output/audience.md`, `presentation/03_title/output/title.md`, and `presentation/shared/references/GLOBAL_CONTEXT.md`.

## Process

Build a **5-slide** structure based on the blog post content:

1. **Title slide** — Presentation title, company name/logo placeholder, date
2. **The Threat Landscape** — Why this protocol is needed (increasing cyber threats, NIST reference)
3. **The New Protocol** — Three components: MFA, quarterly security audits, employee training
4. **Benefits** — Enhanced security, reduced disruptions, improved cash flow, customer trust
5. **What You Need to Do** — Call to action, compliance is mandatory, next steps

## Output

Write the following to `presentation/04_structure/output/`:

| File | Contents |
|------|----------|
| `structure.md` | 5-slide outline with slide numbers and titles |
