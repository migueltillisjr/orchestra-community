# Stage 9 — Evaluation

Critically evaluate the final presentation against the requirements and grading rubric.

## Input

Read `presentation/08_final_assembly/output/final_presentation.html` for the completed presentation.

## Process

1. Read `presentation/shared/references/REQUIREMENTS.md` and `presentation/shared/references/RUBRIC.md`.
2. For **each** section in the rubric, find specific content in the presentation that satisfies it.
3. Assign ratings: ✅ Competent, ⚠️ Approaching Competence, or ❌ Not Evident.

**Do NOT give benefit of the doubt. If you cannot point to specific content, it does not pass.**

## Output

**Use the `write` tool to save to `presentation/09_evaluation/output/evaluation.md`.**

| File | Contents |
|------|----------|
| `evaluation.md` | Full evaluation with ratings, evidence, summary, and recommendations |

## Run Versioning

- First run: `evaluation.md`
- Subsequent runs: `evaluation_<YYYYMMDD_HHMMSS>.md`

**REMINDER: Use the `write` tool to create this file on disk.**
