# Stage 3 — Create a Strong Title

## Input

Read `presentation/01_purpose/output/purpose.md` and `presentation/02_audience/output/audience.md`.

## Process

1. The title must convey the rollout of a new cybersecurity protocol.
2. Reference the blog post title "Heads Up, Cybersecurity Changes" as inspiration.
3. Make it clear, engaging, and action-oriented.
4. Propose 3–5 options and select the strongest one.

## Output

Write the following to `presentation/03_title/output/`:

| File | Contents |
|------|----------|
| `title.md` | The chosen title and 2–3 alternatives considered |
