# Stage 5 — Evaluation

Critically evaluate the final message against the requirements and grading rubric.

## Input

Read `imessage/04_final_assembly/output/final_message.md` for the completed message.

## Process

1. Read `imessage/shared/references/GLOBAL_CONTEXT.md` and `imessage/shared/references/RUBRIC.md`.
2. For **each** section in the rubric, find specific content in the message that satisfies it.
3. Assign ratings: ✅ Competent, ⚠️ Approaching Competence, or ❌ Not Evident.

**Do NOT give benefit of the doubt. If you cannot point to specific content, it does not pass.**

## Output

**Use the `write` tool to save to `imessage/05_evaluation/output/evaluation.md`.**

| File | Contents |
|------|----------|
| `evaluation.md` | Full evaluation with ratings, evidence, summary, and recommendations |

## Run Versioning

- First run: `evaluation.md`
- Subsequent runs: `evaluation_<YYYYMMDD_HHMMSS>.md`

**REMINDER: Use the `write` tool to create this file on disk.**
